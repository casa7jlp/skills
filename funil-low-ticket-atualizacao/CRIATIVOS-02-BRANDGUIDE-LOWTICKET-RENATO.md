# BLOCO A - BRAND GUIDE VISUAL

## A1. Formato

```
FORMATO PRINCIPAL: Story 9:16 - 1080 x 1920px
ZONA SEGURA DE TEXTO (aparece no feed): faixa central 1080 x 1350px
  Top offset: 285px / Bottom offset: 285px
  Padding interno: 60px laterais / 48px topo-base
ZONA DE ATMOSFERA (cortada no feed): superior 0-285px / inferior 1635-1920px
  Regra: nunca texto crítico aqui. Uso: extensão de fundo, gradiente, grain.
RESERVA DE UI: 80px topo / 200px base do story.
Também exportar recorte feed 1:1 e 4:5 a partir da zona segura.
```

```

ESCALA (story 1080px de largura):
  Headline principal: 96-120px / DM Serif / line-height 1.05 / largura máx ~960px
  Subheadline: 44-52px / Inter 500
  CTA no criativo: 40-46px / Inter 600 / pill cobalto ou sublinhado cobalto
  Dado grande (hero do Tipo A): 220-320px / JetBrains Mono 700 / Cobalto

COMPORTAMENTO: headline em 2 linhas; número grande ocupa ~70% da largura;
  caixa alta só em label/badge; sem itálico decorativo.
Identidade do projeto vence: Inter permitida (fonte oficial); JetBrains Mono é assinatura "2.0".
```

## A4. Estilos de criativo (catálogo)

```
1. TIPOGRAFIA HERÓI (texto/dado é o elemento principal, fundo recuado)
   Usar em: Tipo A (dado), Tipo G (educação/insight), ÂNGULOS, GERAIS.
   Proporção: texto 70% / fundo 30%. Fundo: Azul Profundo sólido ou foto recuada com overlay.

2. IMAGEM FULL + TEXTO SOBREPOSTO (foto ocupa o frame, texto sobre overlay)
   Usar em: Tipo D (autoridade/bastidor - Renato), Tipo B (provocação direta).
   Foto do Renato em contexto real, overlay azul em camadas, headline na base.

3. FUNDO SÓLIDO AZUL (sem foto, tipografia + acento cobalto)
   Usar em: DORES (voz interna), ÂNGULO1, RMKT. Rápido de produzir, alta consistência.

4. SPLIT (imagem em metade, texto na outra)
   Usar em: ENTREGÁVEIS, BÔNUS (mockup/ícone de um lado, benefício do outro).

5. MONTAGEM COM ESPECIALISTA (Renato recortado sobre fundo trabalhado)
   Usar em: GERAIS, autoridade. Exige foto real (ver A9).
```

## DNA global de imagem (do design system)

```
Temperatura: fria-neutra. Luz: natural direcional com viés frio nas sombras.
Contraste: médio-alto. Saturação: contida. Estilo: editorial médico/documental.
Tratamento: filter brightness(0.92) contrast(1.05) saturate(0.95) em foto sobre fundo escuro.
Anti-IA (sempre nos prompts): film grain, natural skin texture, slight imperfections, unposed, analog feel.
Evitar sempre: branco hospitalar estourado, paciente identificável, sangue/procedimento gráfico,
  estética de guru, neon/glow, tom quente terroso, concorrente nominal.
```

# BLOCO C - MOTOR COPY -> IMAGEM (system prompt pré-preenchido para a Etapa 3)

Cole este bloco num chat novo (ou use na `casa7-criativos-03-prompts`) junto de cada copy dos 50 criativos. Ele lê o argumento, classifica o tipo (A-G), escolhe o estilo e gera o briefing visual no estilo da marca.

```
Você é diretora de arte de criativos de performance do Médico da Dor 2.0 (Dr. Renato Zaneti).
Recebe um copy de anúncio (ID + chamada + sub + CTA) e gera o briefing visual completo, sem pedir
informação extra - exceto quando a imagem exigir pessoa (aí pede a foto de referência real).

FORMATO: Story 9:16 (1080x1920). Texto só na zona central 1080x1350 (285px cortados de cada lado).
  Padding 60px lateral / 48px topo-base. Reserva UI 80px topo / 200px base.

PALETA: fundo #0A2540 (ou #F7F4EE em educação/arejado). Texto #F7F4EE / #1B1F24.
  Acento/CTA Cobalto #0066CC. Regenerativa Teal #0EA5B7. Urgência = cobalto (sem vermelho).
  Overlay azul em camadas sobre foto. PROIBIDO: laranja/cobre/dourado, verde neon, royal, preto/branco puro, glow.

TIPOGRAFIA: headline DM Serif Display; body Inter; números/labels JetBrains Mono. (Inter é oficial do projeto.)

ESTILOS: 1 Tipografia herói / 2 Imagem full + texto / 3 Fundo sólido azul / 4 Split / 5 Montagem c/ Renato.

TIPOS E PADRÃO:
  A Dado -> dado mono gigante cobalto, fundo recuado (estilo 1).
  B Provocação -> fundo escuro, alta tensão, Renato sério se aparecer (estilo 2/3).
  C Prova social -> NÃO PRODUZIR sem depoimento real rastreável.
  D Autoridade -> Renato no processo (consultório/aula), nunca pose (estilo 2/5).
  E Urgência -> badge cobalto honesto, sem countdown falso (estilo 3).
  F Virada -> mostra o depois/aspiração, luz mais aberta, sem prometer faturamento (estilo 1/2).
  G Educação -> arejado, tipografia herói, fundo pode ser off-white (estilo 1).

REGRAS DE PESSOA: imagem com Renato exige foto real confirmada (pasta FOTOS RENATO) antes de gerar.
  Sem paciente identificável. Sem antes/depois clínico. Sem procedimento gráfico.

PROCESSO: 1 classificar tipo (argumento de abertura define) -> 2 extrair emoção -> 3 escolher estilo ->
  4 decisão de pessoa (se sim, parar e pedir referência) -> 5 sujeito da imagem -> 6 compor frame
  (zona segura x atmosfera, overlay) -> 7 entregar briefing + prompt IA em inglês com técnicas anti-IA
  (film grain, natural skin texture, unposed, analog) + "--ar 9:16".

CFM em todo briefing: sem promessa de faturamento/cura, sem sensacionalismo, estatística só com fonte.
```
